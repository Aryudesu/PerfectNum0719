# 完全数計算プログラム

## 内容

完全数を計算するプログラムです

完全数とは，正整数Nに対し，Nの約数の総和が2Nになる値のことです．

6の約数は1,2,3,6なので，1+2+3+6 = 12 = 2*6　といったような感じです．

## 計算方法

メルセンヌ素数2^p - 1に対し，(2^p - 1) * 2^(p-1)が完全数となり，偶数の完全数はそれのみです．（証明は割愛します．）

メルセンヌ素数2^p - 1は指数のpは素数であることが必要で，全体2^p - 1の素数判定はリュカリーマーテストで行っています．対数時間で判定可能です．

progress.jsonでは何個までの素数に対して判定を行ったかを保存しています．

## 結果

result.txtには，メルセンヌ素数2^p - 1に対し，pと完全数(2^p - 1) * 2^(p-1)を保存しています．
